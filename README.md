# NicaExport-Trading-S.

## Descripción del proyecto

Este proyecto corresponde al análisis y gestión de las operaciones de comercio internacional de NicaExport Trading, S.A.

La empresa realiza exportaciones de productos agroindustriales hacia diferentes mercados internacionales. El proyecto analiza las operaciones realizadas durante el primer semestre de 2026.

## Objetivo

Analizar las operaciones de exportación de NicaExport Trading, S.A. para identificar los mercados más importantes, los productos con mayor demanda, las operaciones que generan mayores ingresos y utilidad, los principales clientes y las operaciones que requieren atención.

## Herramientas utilizadas

- Microsoft Excel
- Microsoft PowerPoint
- GitHub

## Contenido del proyecto

### Excel
Contiene el análisis de las operaciones internacionales, incluyendo fórmulas, cálculos, tablas dinámicas y gráficos.

### PowerPoint
Contiene la presentación de los principales resultados, hallazgos, conclusiones y recomendaciones del análisis.
